# 南投國中 115 學年度親師座談手冊

這是南投國中親師座談手冊的響應式網頁版，提供家長以手機或電腦分頁閱讀。

## 功能

- 章節分頁導覽
- 上一頁／下一頁切換
- 手機版響應式版面
- 37 頁手冊內容完整保留
- 可開啟原始 PDF

## 本機預覽

直接開啟 `index.html`，或使用以下指令啟動本機伺服器：

```bash
python -m http.server 8765
```

再瀏覽 `http://localhost:8765/`。

## 部署

本專案為純 HTML、CSS、JavaScript，可直接部署到 GitHub Pages、Netlify 或任何靜態網站服務。
